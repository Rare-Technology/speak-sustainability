Install

Install: Speak Sustainability

Choose your primary method of use.

Appears as Speak Sustainability in ChatGPT's Skills list. In Claude and Gemini, it shows as the lowercase speak-sustainability — that's expected, not a typo; only ChatGPT supports a separate display name. The steps below use whichever name each client actually shows.

Path A

Use with Web/Desktop LLM Clients

Download Standard Package (.zip) Using Claude? Download the Claude-specific package instead →

For ChatGPT and Gemini, use the standard package. Claude needs its own package — see the note above.

  1. In the ChatGPT sidebar, select Plugins.
  2. Open the Skills tab.
  3. Select Create, then Upload from your computer.
  4. Upload speak-sustainability.zip.
Next: verify it worked ↓
  1. Make sure Code execution and file creation is enabled in Settings → Capabilities.
  2. Open Customize → Skills.
  3. Select +, then Create skill → Upload a skill.
  4. Upload speak-sustainability-claude.zip and make sure the skill is enabled.
Next: verify it worked ↓
  1. Open Gemini or the Gemini app on Mac.
  2. Select Switch to Spark → Skills.
  3. Select Upload and choose speak-sustainability.zip.
  4. Review the skill, then select Create.
Next: verify it worked ↓
  1. In the Gemini Enterprise navigation menu, select Skills.
  2. Select Import.
  3. Upload speak-sustainability.zip, then select Import.
Next: verify it worked ↓

Path B

Use with Command-Line Agents

Claude Code, Codex, Gemini CLI, Cursor, or another supported agent.

Requires a desktop or laptop with Node.js installed — this path won't work from a phone or tablet. On mobile, use Web/Desktop LLM Clients instead.

Terminal 
npx skills add https://github.com/Rare-Technology/speak-sustainability-skill/tree/main/skill/speak-sustainability --global

The installer prompts you to choose an available agent. Omit --global for a project-only installation.

Next: verify it worked ↓

Verification

Verify installation

Works the same way for either path — right inside your client, not here.

Start a new chat first — a chat that was already open before you installed may not pick up the skill.

Prompt 
Review this:

Our organization is committed to achieving net-zero emissions by 2050 through ambitious decarbonization strategies and nature-based solutions. The climate crisis is an existential threat, and if we don't act now, it will be too late. Join us in making a difference for the planet.

Have your own copy handy? Paste that in instead of the example above — either way, ask for a review the same way.

Confirm it actually ran — look for both of these:

  • While it works: a short activity step showing it's using the Speak Sustainability skill (exact wording varies by client).
  • In the answer: a short review in three parts — how the piece reads, what's already working, what to change — quoting your actual wording back (e.g. "net-zero," "existential threat") rather than generic writing tips.

Troubleshooting

If something doesn't work

Turn on Code execution and file creation under Settings → Capabilities first — the Skills upload option only appears once that's enabled.

Make sure you downloaded the Claude-specific package, not the standard one — Claude won't run the standard package. After uploading, confirm the skill shows as enabled in your Skills list.

Skills is a newer feature and may not be enabled yet on every account or workspace. If it's missing, check for a pending app update, or ask your workspace admin whether it's been turned on.

Custom skill imports are usually controlled by your organization's Gemini Enterprise admin. If Import isn't available, ask them to enable it for your account.

You'll need Node.js (with npx) installed. The installer prompts you to pick from the agents it detects on your machine — if none show up, confirm your agent's own CLI is installed and up to date, then try again.

Confirm the skill shows as enabled in your client's Skills list, then start a new chat before pasting your copy in — some clients only pick up newly installed skills in a fresh conversation.
